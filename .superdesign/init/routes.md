# Route inventory

Generated from the real codebase on 2026-08-01.

## Web route map

- `/`: session-aware entry redirect.
- `/login`: authentication.
- `/app`: authenticated application shell.
- `/app/p/:pageId/:view`: main calendar Page in day/week/month/agenda views.
- `/app/p/:pageId/event/new`: full event creation editor.
- `/app/p/:pageId/event/:eventId`: full event editor.
- `/healthz` and `/favicon.ico`: non-visual utility routes.

## Native route map

- Root chooses auth, onboarding or tabs from session/setup state.
- Auth stack: welcome, sign in and sign up.
- Tab shell: calendar, agenda, calendars and settings.
- Onboarding stack: introduction, calendar, share and sync.
- Invite token and not-found are top-level exception routes.
